Build Tracker Chat Sync

Sends the conversation ID and title of the Claude chat you're on to your Build Tracker's ingest endpoint, so it shows up ready to link instead of a bare conversation ID you have to paste in yourself.

"Send to Builder" — the button that shows up on a build-prompt copy block in claude.ai, launching a local Claude Code session for it via the mybuilder:// protocol (scripts/setup-extension-host.ps1 registers the local handler). These defaults get passed along every time; leave any of them blank to skip that parameter.

"+ New chat for this epic" — shown on the Browse Epics screen when an epic has no chat linked yet. Opens the project URL below in a new tab, pre-filled with "Epic #N" plus (optional) a token you paste in below — not a server secret, just whatever short-lived text you want handed to the new chat. Leave the token blank to only prefill the epic reference.
