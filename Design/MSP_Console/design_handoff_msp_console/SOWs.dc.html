RECORD AN ACCEPTANCE · FILED AS A SECURITY BUG The write side checks nobody's ownership
The read route refuses a customer outside your MSP. The write route does not: any signed-in account in the system — another MSP's staff, an unrelated customer login — can post an acceptance against any customer id and it succeeds, writing a permanent record with the agreement text, an IP address and a user agent that reads exactly like a genuine acceptance. It is a legally relevant compliance record, forgeable across tenants. This screen keeps the action behind a confirmation and labels what it writes, but the guard has to land on the server.
