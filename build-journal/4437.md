## Log
- 2026-09-17T02:10:00Z ⏳ IN FLIGHT — confirmed root cause: `DevDatabaseResetGate.cs`'s old `BackupLine` regex matched both the script's "Taking backup: <path>" (starting marker, printed before pg_dump) and "Backup: <path>" (final, only printed after a successful pg_dump + pg_restore --list verification per `reset-dev-database.mjs:296-316,508`), taking whichever line appeared last. On a pg_dump failure only the starting marker exists, so it was reported as a completed backup. Fixing to require the final "Backup:" summary line AND "Backup verified:" line before claiming success; otherwise report the attempted path as incomplete.
