  WebView2) and `BT_OPEN_ISSUE` (delegates to `_owner.OpenGitDetailByNumberAsync(n)`, the same method
  MainWindow's own chat surface uses) — real reuse, not a parallel mechanism. Verification:
  `dotnet build BuildConsole.csproj` clean, 0 warnings/0 errors. Live UI verification limitation
