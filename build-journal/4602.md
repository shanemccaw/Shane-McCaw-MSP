## Changes Made
- `artifacts/api-server/src/lib/monitor-executor.ts` — added `countIfFieldOlderThan(N)` transform: compares the mapping rule's own `sourceField`-resolved value against the cutoff (via the already-resolved `vals` array), instead of a hardcoded `signInActivity.lastSignInDateTime` path. A missing value is NOT counted as stale (under-report + warn), unlike `countIfLastSignInOlderThan`'s "never signed in counts as stale" convention — this is exactly the bug being fixed. `countIfLastSignInOlderThan`'s own case block, and its real callers (`identity:stale-accounts`, `governance:guest-staleness`), are untouched.
- `artifacts/api-server/src/lib/__tests__/monitor-executor.test.ts` — two new tests: correct stale/fresh split against `lastModifiedDateTime` (the real #4602 shape), and the missing-field-warns-not-counts-stale case.
- `artifacts/api-server/src/lib/monitor-check-trace.ts`, `artifacts/admin-panel/src/adminv2/screens/endpoints/EndpointsBody.tsx` — doc-comment transform-name lists updated (no logic change).
