# Git #3173 — check-migration-numbers.mjs standalone CLI entry never fires on Windows/Git Bash

- **Status:** ⏳ IN FLIGHT 2026-09-07T00:00:00Z
- **Scope:** platform

## Log
- 2026-09-07T00:00:00Z — Confirmed root cause per issue body: `import.meta.url === \`file://${process.argv[1]}\`` never matches on Windows because `process.argv[1]` uses backslashes while `import.meta.url` is a forward-slash `file://` URL. Fixed by comparing `fileURLToPath(import.meta.url) === resolve(process.argv[1])` in `scripts/check-migration-numbers.mjs`. Verified `node scripts/check-migration-numbers.mjs` now actually runs and prints the OK line (previously silently exited 0 with no output).
