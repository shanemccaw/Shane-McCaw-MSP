## Log
- 2026-09-12T16:15:00Z ⏳ IN FLIGHT — Investigating why a self-detected 🛑 BLOCKED bookend commit (the #3623 layer-2 self-check path) lands only on the agent branch / dev-server checkout and never reaches origin/main, while the watcher still marks the row Verifying on clean exit (confirmed cases: #3584, #3585).
- 2026-09-12T17:05:00Z ✅ DONE — Root cause confirmed: `WorktreeProvisionService.MergeBackAsync` (via `request-restart.mjs`) only ever publishes a completed worktree's commits into the LOCAL dev-server checkout, never to `origin/main`; `DoneBookendVerifier.GetBlockedAsync` (the false-done reconciler's Shape-A correction) reads `origin/main:build-journal/{n}.md`, exactly the ref a self-blocked session's bookend never reached — so neither the initial reap nor the manual-refresh reconciler could ever see it. Fix, commit 6b2d9eabd on `main`:
  - New `scripts/dev-server/push-blocked-bookend.mjs` (+ `push-blocked-bookend.selftest.mjs`, 15/15 passing): reads the worktree's own committed bookend at HEAD (not origin/main) and, only when its effective `**Status:**` says BLOCKED, pushes that HEAD directly to `origin/main` (one fetch+rebase retry if main moved under a peer's commit — selftest proves the peer's commit is preserved, not clobbered).
  - `WorktreeProvisionService.PushBlockedBookendIfAnyAsync` — thin C# dispatcher to that script (same convention as `MergeBackAsync`).
  - `QueueWatcherService`'s reap loop (new `RunningEntry.GithubNumber` field) calls it right after a worktree build exits 0, before the cleanup sweep can reclaim the worktree; on a genuine BLOCKED bookend it reuses the existing Shape-A correction (`MarkFalseDoneReconciledAsync` → `canceled`, board → Backlog via `BoardStatusSync.Mirror`) immediately instead of waiting on a manual refresh.
  - `CLAUDE.md`'s "blocked" self-check flow (§ blocked label) now explicitly tells a session to commit+push its own BLOCKED bookend before stopping, same discipline as DONE — the watcher-side fix is a backstop, not a replacement.
  - Verified: `dotnet build BuildConsole.csproj` — 0 errors (pre-existing unrelated warnings only). `node scripts/dev-server/push-blocked-bookend.selftest.mjs` — 15/15 assertions pass. `node scripts/dev-server/verify-branch-merged.mjs` confirms `6b2d9eabd` is a real ancestor of `origin/main`.
