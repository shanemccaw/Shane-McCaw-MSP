  `web/shanes-life/public/app.js` (~line 6974) gates the live-camera scan path on
  `"BarcodeDetector" in window`, which Safari has never implemented (any context, not just PWA).
  Real fallback there today is manual-entry-only. Replacing with a real cross-browser JS decoder
  (`@zxing/browser`, vendored as a static UMD file since this app has no client bundler) that
  decodes frames from the existing `getUserMedia` video stream in software, so Safari/iOS gets a
  real working scanner instead of manual-entry-only.
