# Git #3133 — Shane's Life: "(Invalid Date)" on last-price line

- **Status:** ⏳ IN FLIGHT 2026-09-07T23:00:00Z
- **Scope:** platform

## Log
- 2026-09-07T23:00:00Z — Started. Root cause already confirmed in issue correction comment:
  `whenDate()` in `web/shanes-life/public/app.js` assumed `isoDate` was a bare
  `"YYYY-MM-DD"` string and appended `T00:00:00` to it. The real value passed in
  (`item.lastPrice.observedOn`, from `item_prices.observed_on`) comes back as a full ISO
  timestamp (`"2026-09-07T04:00:00.000Z"`) because `item_prices.observed_on` is a SQL
  `date` column (confirmed in `migrations/021_item_prices.sql:35` — already the right
  column type, no schema change needed) but node-postgres parses `date` into a JS `Date`
  object, and the API layer's JSON serialization emits that as a full ISO timestamp, not
  a bare date string. Concatenating `T00:00:00` onto that produced the malformed
  `"...ZT00:00:00"` string, hence `Invalid Date`.
