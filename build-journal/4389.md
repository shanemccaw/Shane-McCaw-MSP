- 2026-09-16T00:45:00Z ✅ DONE — Replaced `PushArtifactCommitWithRebaseAsync` with `UiAutomationQaSessionService.PublishArtifactCommitIsolatedAsync`: builds the artifact commit via `git commit-tree` against a throwaway `GIT_INDEX_FILE`-backed index (`read-tree origin/<branch>` + `add -- <relArtifactPath>` only), then `git push origin <sha>:<branch>` with fetch-and-retry on non-fast-forward. Never runs `git add`/`git commit`/`git rebase`/`git reset` against the checkout's real `.git/index` or HEAD. Both callers (`UiAutomationQaSessionService.FinalizeAutomationSessionAsync`, `VisualTestTrackerSessionSyncService.StageCommitPushAsync`) switched over; the old rebase-based method and its doc-comment references (`BuildConsoleSettings.cs`) removed/updated.
