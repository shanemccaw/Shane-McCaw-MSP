    started only recently — not concurrent-agent leakage.

    `sha256-` + base64(sha256(LF `.pnpmfile.cjs`)) == `sha256-GyU/...` byte-for-byte.
    pnpm normalizes to LF before hashing, so the checksum is cross-platform stable
    (same on Windows CRLF checkouts, worktrees, and Replit LF) — no `.gitattributes`
    EOL pin needed.
