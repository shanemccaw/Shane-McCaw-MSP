  ### Reconciled against the finished code, not against this issue's list

  The issue's list survived, with three real corrections, each stated on #1843:

  1. **"Assess a tenant against a baseline" had no baseline.** #1797 landed
     `diffAgainstBaseline(knownGoodSnapshotRowId, …)`, but nothing in the store said WHICH

     `drift_baseline_snapshots` is the drift engine's per-domain `(text tenant_id, domain_key)`

  ### Two bugs found by RUNNING the routes rather than reading them

  - **Mount prefix.** `app.ts:115` mounts everything at `app.use("/api", router)`, so a path
    registered inside a router must not repeat `/api`. Mine did and were served at
    `/api/api/…`; fixed in `41317c2b4` and the trap documented in each file header. The same
    defect in #1798's `admin-config-snapshots.ts` / `admin-config-diffs.ts` is REAL and
    unfixed — those two are the only such files in the whole routes directory, and both of
    #1798's admin-panel pages fetch the correct path and get a 404. Filed as **#2099** with
    the live 404-vs-200 evidence; not fixed here because changing that surface needs an
    end-to-end check of those pages, which is #1798's scope.
  - **The duplicate-name 409 never fired.** Drizzle wraps the driver error in a
    `_DrizzleQueryError` whose own `message` holds only the SQL and bound parameters — the
    constraint name lives on the pg error underneath — so matching `err.message` silently
    never matched and the case fell through to a 500. Now walks the cause chain; 409 confirmed
    live.
