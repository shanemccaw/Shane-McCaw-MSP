## Log
- 2026-08-27 ⏳ IN FLIGHT — confirmed root cause: `ProcessStartInfo.Environment` starts as a copy of BuildConsole's own process environment, so `QueueWatcherService.LaunchItem`'s `--account secondary` path only ever ADDED `CLAUDE_CONFIG_DIR` without removing an inherited `CLAUDE_CODE_OAUTH_TOKEN`/`ANTHROPIC_API_KEY`, which the Claude Code CLI authenticates off directly when present — silently overriding the secondary config dir every time. Fixing by stripping both from the spawned env when secondary is selected.
