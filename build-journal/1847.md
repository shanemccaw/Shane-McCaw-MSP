  `encryption-status`, `enrollment-status`, `kfm-configuration`, `os-patch-compliance`,

  **Built.**
  - `tenant_service_availability` — ONE row per (tenant, service): state, reason, evidence
    basis, wire signature, observed endpoint/status, verbatim evidence. The ten checks refer
    to it instead of each announcing the same tenant-wide condition.

    to answer, derived from `graph_path` (not `workload`, which labels 226 of the 261
    `/deviceManagement*` rows `MicrosoftGraph`). 261 rows backfilled.

    signature alone provably cannot separate "never enrolled" from "never licensed"; only
    the entitlement can, and those are different customer conversations.
  - New executor status `service_not_configured`, wired through every consumer that would
