# Git #2169 — BuildQueueMapWindow NRE on open

- **Status:** ⏳ IN FLIGHT 2026-09-01T23:00:00Z
- **Scope:** buildconsole

## Log
- 2026-09-01T23:00:00Z — Confirmed root cause: BuildQueueMapWindow.xaml.cs constructs the `_timer` field after `InitializeComponent()`, but the XAML sets `AutoRefreshToggle IsChecked="True"` which fires `AutoRefreshToggle_Changed` during `InitializeComponent()`, calling `_timer.Start()` on a null field, throwing a NullReferenceException. Fix: move `_timer` construction + Tick wiring before `InitializeComponent()`.
