# Build plan — Git #4472

## Problem Description

Three `node:test` suites in `artifacts/api-server/src/routes/` fail at ESM
module-load time, before any test executes:

- `auth-impersonation.test.ts`
- `auth-account-activation-entitlement.test.ts`
- `auth-forgot-password-surface.test.ts`

Error: `SyntaxError: The requested module '@workspace/db' does not provide an
export named 'auditLogsTable'`

## Root Cause Analysis

Each suite mocks `@workspace/db` via `mock.module("@workspace/db", {
namedExports: { ... } })` before importing the real `auth.ts` router, e.g.
https://github.com/shanemccaw/Shane-McCaw-MSP/blob/main/artifacts/api-server/src/routes/auth-impersonation.test.ts#L77-L101

`auth.ts` imports `createAuditLog` from `lib/audit.ts`, which imports
`auditLogsTable` from `@workspace/db`:
https://github.com/shanemccaw/Shane-McCaw-MSP/blob/main/artifacts/api-server/src/lib/audit.ts#L1-L6

Since the three mocks' `namedExports` objects don't include `auditLogsTable`,
Node's ESM linker fails when `lib/audit.ts` tries to import it from the
mocked module — a hard SyntaxError at load time, before any test body runs.
This is a pre-existing gap, unrelated to #4408 (confirmed in the issue body
by reproducing against pre-#4408 file versions).

## Proposed Changes

Add `auditLogsTable: {}` to the `namedExports` object in each of the three
mocks:
- `artifacts/api-server/src/routes/auth-impersonation.test.ts` (mock at ~line 77)
- `artifacts/api-server/src/routes/auth-account-activation-entitlement.test.ts`
- `artifacts/api-server/src/routes/auth-forgot-password-surface.test.ts`

Checked `lib/audit.ts`'s full import from `@workspace/db` — only `db`,
`auditLogsTable`, and two type-only imports (`AuditActorRole`,
`AuditActionCategory`, erased at runtime). No other named export is needed
beyond `auditLogsTable`.

## Verification Plan

Run, from `artifacts/api-server`:
```
node --experimental-strip-types --experimental-test-module-mocks --test src/routes/auth-impersonation.test.ts src/routes/auth-account-activation-entitlement.test.ts src/routes/auth-forgot-password-surface.test.ts
```
Expect all three suites to load and their tests to pass (0 fail). If any
further missing export surfaces, add it and re-run rather than stopping at
the first error.
