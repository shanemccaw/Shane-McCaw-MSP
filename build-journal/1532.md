## Log
- 2026-08-28 ⏳ IN FLIGHT — The interpretation layer for the Microsoft Changes module
  (part of #1494). An interpretation is authored ONCE per MSP and applies to every
  tenant. Fields: change class (retirement/default flip/new feature/breaking change/
  licensing), what it touches (service/protocol/SKU/setting), who acts (Microsoft vs
  admin), controllable + how, and the probe (what to count in a tenant to know if it
  applies). Shane authors; AI proposes the structured reading from bodyContent/roadmap
  description; Shane confirms before it reaches any tenant — no unverified interpretation
  is ever applied. Structurally per-MSP even though there is one MSP today. AdminV2 only
  for the authoring surface (Gallery + Peek + Ribbon + Watch, no sidebar). Scope: schema
  + AdminV2 authoring surface. channel: "integration.azure".
