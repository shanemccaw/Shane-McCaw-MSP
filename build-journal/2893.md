- 2026-09-04T00:00:00Z ⏳ IN FLIGHT — Confirmed root cause per issue body: `PlaidLinkWindow.StartWebViewAsync()` uses `LinkWebView.NavigateToString(...)`, which gives the document an opaque `null` origin. Plaid's own `flink.js` bundle calls `window.postMessage(msg, targetOrigin)` internally for its own iframe comms and Chromium throws `SyntaxError: Invalid target origin 'null'` — uncaught inside Plaid's bundle, so it never reaches this app's own onerror/watchdog handling from #2888. Implementing the fix exactly as specified: write the Link HTML to a real temp file, use `CoreWebView2.SetVirtualHostNameToFolderMapping` to give it a real virtual origin (`https://shanessurvival.local/link.html`), navigate to that instead of `NavigateToString`, clean up on window close. Confirmed via grep this is the only `NavigateToString` call in ShanesSurvival.
