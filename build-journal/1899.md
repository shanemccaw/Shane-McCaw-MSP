## Log
- 2026-09-04T07:13:56Z ⏳ IN FLIGHT — Researched the real Graph mechanism for forcing MFA
  re-registration. `POST /users/{id}/authentication/methods` is not a writable Graph v1.0
  collection (confirmed against Microsoft Learn). The real mechanism (same one the Entra
  admin center's "Require re-register MFA" button uses): GET the user's current
  authentication methods, then DELETE each phone / Microsoft Authenticator / software OATH
  method individually. This is a genuine fan-out (1 GET + N DELETEs) that
  `baseline_action_templates`' single-{endpoint,method,body}-call model cannot express, so
  it needed a dedicated executor branch, not just a DB row edit.
