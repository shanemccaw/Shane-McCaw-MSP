# #1267 — PLATFORM_BUILD.md bookend writes are not concurrency-safe

- **Status:** ✅ DONE
- **Scope:** both (convention change: per-issue bookend files)
- **Started:** 2026-08-26
- **Commit(s):** `fae057813` (build-journal/ + convention README + bookends) · `e1c597bae` (freeze PLATFORM_BUILD.md + BUILD_LOG.md; rewrite CLAUDE.md bookend + shared-file sections)

Addressed structurally by [[1371]]'s session as the new `build-journal/` convention:
one file per issue, one writer per file. The whole failure class documented on #1267
(one session's DONE commit deleting another's IN FLIGHT row; line-count-based edits
clobbering a sibling row; stale-index bleed on a shared append — 6 real recurrences)
becomes impossible when sessions no longer share a single append target.
