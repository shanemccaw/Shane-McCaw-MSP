# #4864 — Plan: Tasks room (storage + MCP tools only)

## Problem Description
Shane's Life has no real to-do primitive. A genuine task ("call bankruptcy attorney candidates Monday 9/21") landed as inert text in `capture()`. Dates ([push_date](https://github.com/shanemccaw/Shane-McCaw-MSP/blob/main/web/shanes-life/src/mcp/tools.mjs)) is appointment/recurrence-shaped with per-kind lead times; a Task is a one-time done/not-done item with an optional due date. Scope is MCP-only: a `tasks` table plus `push_task`, `list_tasks`, `complete_task`. No UI, no nudges.

## Root Cause Analysis
No `tasks` table exists (confirmed: `\d tasks` on local DB returns nothing; no migration in [migrations/](https://github.com/shanemccaw/Shane-McCaw-MSP/blob/main/web/shanes-life/migrations) mentions it; last is `074_recovery_codes.sql`, and `desktop/ShanesSurvival/migrations` tops out at 012, so 075 is free). `create_entity` could hold one but nothing routes to-dos there.

## Proposed Changes
- New [`migrations/075_tasks.sql`](https://github.com/shanemccaw/Shane-McCaw-MSP/blob/main/web/shanes-life/migrations/075_tasks.sql): `tasks(id, user_id, title, notes, due_date, status open|done CHECK, completed_at, created_at)` + index on (user_id, status, due_date), ends with self-marking insert only if the surrounding runner convention requires (Shane's Life runner tracks via `schema_migrations`, so no `simulator_migration_runs` row).
- New [`src/core/tasks.mjs`](https://github.com/shanemccaw/Shane-McCaw-MSP/blob/main/web/shanes-life/src/core/tasks.mjs): `createTask`, `listTasks` (status default open, optional dueBefore), `completeTask` (idempotent, keeps first completed_at). Modelled on [`wins.mjs`](https://github.com/shanemccaw/Shane-McCaw-MSP/blob/main/web/shanes-life/src/core/wins.mjs).
- Edit [`src/mcp/tools.mjs`](https://github.com/shanemccaw/Shane-McCaw-MSP/blob/main/web/shanes-life/src/mcp/tools.mjs): add three tools next to `push_date`/`list_dates`, each writing an `audit` record like their neighbours.
- Edit [`README.md`](https://github.com/shanemccaw/Shane-McCaw-MSP/blob/main/web/shanes-life/README.md) tool list if it enumerates tools.
