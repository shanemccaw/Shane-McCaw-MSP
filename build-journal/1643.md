Fixed by adding `PROJECT_DIR_NOSLASH` (trailing backslash stripped) and using it in all three `git -C` calls; `%PROJECT_DIR%` is untouched everywhere else (BUILD_OUT/OUT_DIR/messages). Re-verified this time by copying the *actual* script file into a throwaway git repo and running it directly (not extracted logic): up-to-date (no-op pull, correct commit, exit 0, proceeds into the real build step), dirty tree (fails closed, exit 1), diverged history (fetch ok, ff-only fails, exit 1) — all against the real file.
