## What shipped

New standalone app at `web/shanes-life/` (47 files). Not a pnpm-workspace package — it is
outside every `packages:` glob in `pnpm-workspace.yaml`, deliberately, so a root install never
touches it and it deploys to Replit on its own.

- **Database** — a real, separate Postgres database `shanes_life`, reached only through
  `DATABASE_URL`. Created locally this session and migrated. Schema in
  `web/shanes-life/migrations/001_foundation.sql`: `users`, `sessions`, `auth_events`,
  `categories`, `captures`, `media`, `entities`, `entity_items`, `share_links`, `mcp_tokens`,
  `activity_log`, `schema_migrations`. Migrations self-apply on boot.
- **Auth** — scrypt (N=2^15) with per-user salt and per-row parameters; opaque revocable
  server-side sessions (SHA-256 stored, `HttpOnly; SameSite=Lax` cookie), not JWTs, because
  "sign out everywhere" has to actually work. Per-address and per-source login rate limiting,
  a durable `auth_events` trail, one identical message for every failure mode, and a
  deliberate hash-anyway path so a missing account is not measurably faster than a wrong
  password. No public sign-up route.
- **Universal capture box** — the single entry point, fixed to the bottom of every screen.
  Text, voice (MediaRecorder), photo (camera input). Attachments stored in Postgres `bytea`,
  not on disk, because Replit's filesystem does not survive a redeploy.
- **Genuinely open classification** — `categories` is a registry table that grows on first
  use, plus unconstrained `data jsonb` on every entity. Nothing in the codebase enumerates
  known categories. `npm run check` asserts this with a runtime-generated slug that appears
  nowhere in the source.
- **No-login share links** — capability URLs. One entity each, optionally tick-only,
  expirable, revocable, attributed (`checked_by = 'share:<label>'`) and audited.
- **Remote MCP server** — hand-written Streamable HTTP (`src/mcp/protocol.mjs`), 12 tools,
  `Authorization: Bearer slmcp_…` or `/mcp/t/<token>`. Every write lands in `activity_log`
  with the token's label. Plus a stdio bridge (`bin/mcp-stdio.mjs`).
- **Home Screen PWA** — manifest, service worker (shell only; it never caches an API
  response), and real PNG icons generated from code by `bin/make-icons.mjs` (a hand-written
  PNG encoder over `node:zlib` — no image library, no download).
- **Replit hosting** — `.replit` (Reserved VM, not Autoscale, for stated reasons) and a
  step-by-step deploy plan in `web/shanes-life/README.md`.

Zero packages downloaded. The one runtime dependency (`pg`) was already resolvable from the
worktree root, so nothing was installed and nothing was fetched over the metered connection.
