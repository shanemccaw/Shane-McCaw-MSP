- 2026-08-30 ⏳ IN FLIGHT — **The load-bearing finding from investigation**, which decides the
  whole shape of this store: `scripts/config-state/build-resource-model.mjs:243` still runs
  `DELETE FROM config_resource_samples`, and the same script deletes and re-inserts every
  `config_resources` row on each run, **re-serialising the primary keys**. `config_resources.id`
  is therefore a volatile identifier. A snapshot store that FKs to it would have its accumulated
  evidence cascade-deleted on the next model rebuild — the exact #1895 failure. Every table in
  this issue keys on the stable text `resource_key` instead, with no FK to `config_resources`,
  following the precedent `config_resource_property_divergence` already set.
