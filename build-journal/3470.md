## What was built
- Ported full-virtual-screen RegionSelectOverlayWindow and physical-pixel desktop capture DesktopScreenClipService into MyArchitect.
- Dual-sink output: clipboard (CF_BITMAP + PNG stream) and disk in %Pictures%\Screenshots\MyArchitect.
- Local screenshot_evidence JSON cache (ScreenshotEvidenceItem & ScreenshotEvidenceService) persisting metadata (capturedAt, filePath, tenantId/name, activeUrl, caption, step/change refs) to %LocalAppData%\MyArchitect.
- Screenshot review and gallery panel UI (ScreenshotGalleryPanel) integrated in the shell with thumbnail list, image preview, metadata viewer, caption editor, explorer launch, and discard support.
- Hooked up PrintScreen and Ctrl+Shift+S hotkeys, navigation bar ScreenClip button, and Activity Bar gallery toggle.
- Created IEvidencePostClient documenting the cross-epic dependency on Portal Admin #1571 for remote attachment submission.
