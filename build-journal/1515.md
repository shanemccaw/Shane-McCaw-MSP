- 2026-08-30 ⏳ IN FLIGHT — Foundation for the Ownership/RACI module (#1491). `portal_ownership_assignments` carries a UNIQUE index on `(customer_id, object_id, role_key)` — one holder per RACI cell. Per the issue, R/C/I are routinely many and A is too (NASA runs three A's on M365), so the constraint is wrong for all four letters. Dropping and replacing the unique key with `(customer_id, object_id, role_key, owner_person_id)` so a cell can hold multiple distinct holders while still forbidding the exact same holder twice; A ordering is preserved by insertion order (`id` serial, the read already orders by it). Ordinal column + precedence UI = #1517; holder-reference (person|group) model = #1516; both build on this. This lands first and alone.
