### Deviations from the dispatch / design (all stated in the plan doc)
1. **Tier source confirmed only partly.** `severity_matched` is honest for checks that carry severity rules and silent for the 68 of 155 that carry none (NULL is ambiguous). Those cards get a fifth, neutral state — "Measured — nothing grades this" — rather than a fabricated *good*. Live: 64 of 180 cards are `ungraded`. Filed as an open decision, #4836. `info|low → meh` is the one judgement call, in one function (`signalTier`).
2. **Delta does not use `monitorHistoryForTenant`**: it is private, one query per check, and picks the field by token heuristic (the thing #4560 removed for tiles). One windowed read with the same explicit field as the value instead.
3. **Design sub-captions that assert a demo tenant's state** ("legacy auth is not blocked — MFA can be bypassed", "PowerShell errored") are not carried — they would be false under another tenant's number. Definitional captions and "of N …" captions (N from a real denominator field) are.
4. **"View all checks" link not rendered** — it is the entry point of the out-of-scope drill-down and has no destination.
5. Design's `error` drift state is added (design has only tracked / not comparable) so a failed collection is never worded as clean.
