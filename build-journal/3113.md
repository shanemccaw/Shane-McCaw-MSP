Implements the **revised** scope (Shane's 2026-09-07T18:34:21Z architectural redirect,
which supersedes the original batching-only plan): maintain a real, local, persistent
mirror of GitHub issue state in the existing Postgres DB (`bt_issue_mirror`), have
routine read call sites read from that LOCAL mirror instead of calling GitHub per issue,
and reserve real live GitHub calls for (a) the periodic batched sync/diff (via GraphQL
`nodes(ids:)`, chunked ≤100) and (b) genuinely authoritative real-time checks.
