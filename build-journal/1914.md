- 2026-08-30 ⏳ IN FLIGHT — Confirmed root cause per issue body: `scripts/setup-extension-host.ps1`
  bakes `$PSScriptRoot` into `HKCU:\Software\Classes\mybuilder\shell\open\command` once, at the
  moment it's manually run; nothing re-runs it if the repo root ever changes. Plan: add a C#
  registration (mirroring the ps1's registry writes) wired into `App.OnStartup`, right after

  self-heals on every BuildConsole startup — idempotent, matches the ps1's own documented
  "safe to re-run" contract.
