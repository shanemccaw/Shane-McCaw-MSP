- 2026-09-06T14:36:13Z ✅ DONE — Built the destructive-migration gate and resolved #2930's own orphan as its first real subject. Commit `5fbb3fc4e`, verified an ancestor of `origin/main` via `verify-branch-merged.mjs`.

  **Convention** — `-- @migration-gate: manual|auto-approved` + a required `-- @gate-reason:` line, in the leading comment block of a `lib/db/drizzle/*.sql` file. `manual` is never auto-applied; `auto-approved` is an explicit reasoned sign-off; **a file with no header that nonetheless contains a destructive statement is ALSO held** — the gate fails closed, so forgetting the marker cannot silently execute a DROP. New `migrate-mark-applied` script records a hand-run migration in `__drizzle_migrations` without executing any SQL, which is what lets a held file ever clear.

  **Boundary** — taken verbatim from CLAUDE.md's Database section, not invented: DROP TABLE/COLUMN/SCHEMA/DATABASE/TYPE/SEQUENCE/MATERIALIZED VIEW, TRUNCATE, and DELETE/UPDATE with no WHERE are destructive; DROP CONSTRAINT/INDEX/DEFAULT/NOT NULL/TRIGGER/FUNCTION/POLICY, plain DROP VIEW and any RENAME are not. That right-hand column is load-bearing — the corpus has 6 DROP CONSTRAINT and 3 DROP NOT NULL that must keep flowing through. Detection masks comments and string literals (preserving offsets, so line numbers are real) but deliberately NOT `DO 324 ... 324` bodies, since 0030 hides a real DROP COLUMN inside one.

  **Enforced in three places** — both runners (evaluate from the raw file before any statement reaches the DB), `check-drift` Check 4 (a destructive .sql without a header fails at merge time), and `post-merge.sh` (exit 3 = loud warning, not a broken merge).

  **Real gotcha found and fixed:** `pnpm --filter ... run` collapses every non-zero child exit code to 1 (verified — a script exiting 3 surfaces as ERR_PNPM_RECURSIVE_RUN_FIRST_FAIL, status 1), which would have made exit 3 indistinguishable from a genuine migration failure. `post-merge.sh` now uses `pnpm --dir ./scripts run` for both runners, commented in place so it does not get tidied back.
