  `SemaphoreSlim(2)` bounds only concurrent LOADS, never the total live count — nothing
  disposes a parked preload on successful load (only `TryTakeReopenPreload` via select/close
  removes one), so N persisted tabs = N live claude.ai browsers running simultaneously.
  Fix plan (issue option 1 — bound the TOTAL): cap the preload to a small hot set of the
  most-recently-used persisted tabs (by `SavedAt`); the remaining tabs still get their inert
  placeholder tab in the strip and load normally on click (that path already works). Add a
  configurable cap setting `ChatReopenPreloadMaxTabs` to `BuildConsoleSettings` with a safe
  small default.
