  Behavior unchanged.
- `Services/RbacTestAccountsResetGate.cs` (new) — `PreviewAsync` runs `reset-rbac-test-accounts.mjs --dry-run`, arms
  `reset rbac #<live msp id>` only on exit 0 + `[resolve] real direct MSP id=` + the dry-run rollback line + a
  parseable RESULT JSON. The preview redacts the rolled-back passwords and lists each `TEST_RBAC_*` var a real run
  would add/update. `ExecuteAsync` re-checks and consumes the phrase, runs the script once with no flag, requires
  `[commit] transaction committed.` + parseable JSON, upserts `TEST_RBAC_<ROLE>_EMAIL/_PASSWORD` (#3911 naming)
  through `BuildConsoleSettings.Load()/Save()`, then re-reads settings.json and compares every value. The result
  pane leads with that verification, then the new credentials. Pairs for skipped (deleted, not recreated) accounts
  are left untouched and named (not flagged NeedsReview: the manifest scanner prunes those). No password goes
  to ActivityLog or a toast.
- `CommandPaletteWindow.xaml.cs` — holds a list of gates; confirm mode = the gate whose shape the input matches;
  one destructive run per palette at a time; result/running state tied to the gate that produced it.
- `MainWindow.CommandPalette.cs` — new "Reset RBAC test accounts" row (`RunWithResult = rbacGate.PreviewAsync`);
  both gates created per palette window.
- `Services/BuildConsoleSettings.cs` — public read-only `SettingsFilePath` (for the result pane).
- `scripts/db/README.md` — documents the Command Center gate for the RBAC script.
